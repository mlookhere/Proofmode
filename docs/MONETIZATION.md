# ProofMode — Monetization & Tier Design

## Free
Must remain a great product:
ProofTV, posting, joining/watching, basic Passport/Crews, comments/reactions, standard receipts, core history, sharing and safety.

## Proof+ — test $9.99/mo / $79.99/yr
Near-zero marginal-cost benefits:

**Identity**
premium Passport themes, Receipt skins, app icon, profile accents, trophy-case presentation.

**Insight**
streak analytics, complete history, personal trend charts, comeback analytics, own-post/share analytics.

**Convenience**
saved template collections, expanded private Drop allowance, recap layouts, privacy presets, early access.

Paid cosmetics never masquerade as earned achievement.

## Creator — test $39/mo
Proof+ plus:
large Drops, scheduled/recurring Drops, branded pages, custom receipt theme, cohosts, moderation roles, conversion/referral analytics, cohort insights, web Studio, QR/poster kits, creator CTA.

## Black — target $499/mo or complimentary invitation
Not a consumer “top plan.” It is a private creator/operator network.

Public UI:
“ProofMode Black is a private membership for selected creators, athletes, founders and cultural leaders. Invitation only.”

No Apply.

Benefits:
Creator+, Black identity, private directory, collaboration board, cohost intros, selected featured Drop eligibility, product lab, advanced analytics, organization seats, priority moderation controls, launch asset automation.

Strategic creators may receive time-bounded complimentary Black membership. Track the normal list price so the invitation has real perceived value.

## Upgrade moments
Proof+:
- after meaningful streak
- while customizing Passport/Receipt
- when opening advanced analytics
- after repeated value

Do not put paywall before first feed value or shared content.

Creator:
when launching larger/recurring/branded Drops or after creator traction.

Black:
private invitation only.

## Billing
Use RevenueCat to normalize App Store/Play/web entitlements. Server caches validated entitlement state.

Store/payment policy varies by platform/region and should be checked before each release.
