# v0.8.0 — Challenge Join + Watch

## Summary

ProofMode mobile now turns Explore into a real participation surface: public Drops are discoverable while signed out, and Join/Watch actions persist after authentication.

## Changes

- Explore loads live public `drop` challenges from Supabase.
- Added public `/challenge/[slug]` Drop detail.
- Join uses the existing authenticated `join_challenge_v2` RPC.
- Watch and Unwatch persist in `watched_challenges` under existing RLS.
- Signed-out Join/Watch routes through email magic-link auth and returns to the requested action.
- Preview data remains limited to builds with no Supabase environment configured.
- Added pgTAP coverage for reading and deleting self-owned watch state.

## Architecture

No new state manager, repository layer, backend service, or mutation framework was added. The release reuses the existing Supabase client, root AuthProvider, RPCs, RLS policies, and Expo Router.
