# ProofMode 3.0 — UX & Design Brief

## Feel
Kinetic, high-contrast, playful, competitive, human, slightly irreverent, premium where appropriate.

Avoid corporate productivity UI, crypto aesthetics, grindset-only tone and shame-based streak UX.

## Five tabs
Home | Explore | + | Crews | You

## UX rules
1. Content before configuration.
2. One-handed primary actions.
3. No login wall for public shared content.
4. No blank feed.
5. Templates before blank challenge forms.
6. Always show upload progress/state.
7. Failure always offers a next action.
8. Every public post has a participation doorway.
9. Premium is visible but not obnoxious.
10. Safety controls are easy to find.

## Visual content language
Proof — verified/clean.
Fail — humorous/expressive, not punitive red.
Almost — tension.
Comeback — high contrast.
PR — celebration.
Reset — hopeful.

## Receipt dimensions
1080×1920, 1080×1350, 1080×1080, 1200×630 OG.

Receipt contains creator, type, Drop, key stat, small ProofMode brand, CTA and canonical link.

## Accessibility
captions, contrast, reduced-motion support, non-color-only status, labels, dynamic type where feasible, sane mute/audio behavior.
