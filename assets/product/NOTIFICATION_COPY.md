# Notification Copy Bank

Notifications should report a social/story change, not beg the user to return.

## High-value social
- **Jake challenged you.** He posted the receipt first.
- **Maya replied with proof.** The chain is now ×18.
- **Someone passed you.** You're #2 in Run 1 Mile.
- **Your Crew is one proof away** from passing Team North.
- **Three friends joined** the Drop you shared.

## Journey/story
- **Kyle tried 275 again.** Yesterday did not go well.
- **Tori came back.** Her third attempt is now Day 7.
- **The #1 spot just changed** in your Drop.

## Time-sensitive, use sparingly
- **2 hours left** to post for today's Drop.
- **Round 2 starts tomorrow.** 4 friends already joined.

## Positive recovery
Never say “you failed.” Prefer:
- **That run still counts as 63 days proven.** Start the comeback when you're ready.
- **Missed today?** Your history stays. Tomorrow can be Reset #1.

## Daily cap guideline
Default product target: no more than 2 non-transactional pushes/day unless the user explicitly opts into a high-frequency Crew/Drop.
