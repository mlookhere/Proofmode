# ProofMode 3.0 — Product Definition

**Category:** The participation network.

**Core promise:** Don't just watch it. Try it.

**Primary loop:**
`Watch → Try → Prove → React → Share/Challenge → Recruit → Return`

**Core objects:**
- Post — entertaining attempt content.
- Drop — challenge/event.
- Journey — one person's attempt/story arc.
- Crew — private social room.
- Receipt — shareable verified proof object.
- Passport — durable reputation/identity.

**Five consumer destinations:** Home / Explore / Post / Crews / You.
